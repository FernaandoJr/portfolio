A metrics dashboard that updates without a reload, with combined filters and time series that stay readable when data arrives every second.

## Filter state in the URL

Every filter lives in the query string. An interesting slice becomes a link someone else opens in the same state, and the browser's back button works as undo.

## Streaming without stalling the render

Points arrive over SSE and land in a buffer. The chart redraws on a fixed interval instead of per event — without that, a burst of updates pins the main thread and the UI stutters.
