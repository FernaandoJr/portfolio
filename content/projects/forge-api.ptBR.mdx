Um esqueleto de API que já nasce com as partes chatas resolvidas: autenticação, limite de requisições e documentação que não desatualiza.

## Schema como fonte única

Cada rota declara seu schema com Zod. Dele saem, ao mesmo tempo, a validação em runtime, os tipos do TypeScript e o documento OpenAPI. Não existe um passo separado de escrever documentação, então não existe documentação errada.

## Rate limit por identidade, não por IP

Contar por IP pune escritório inteiro atrás de um NAT. A contagem usa o `sub` do JWT quando existe e cai para o IP só em rota pública.
