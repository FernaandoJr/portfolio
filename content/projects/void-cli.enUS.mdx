A project generator that starts from a real repository instead of a bundled template. The template is a repo you maintain like any other code.

## Nothing is written before the end

Files are assembled in memory and only hit the disk once every step passes. A scaffolding run that fails halfway leaves a folder that does not compile and cannot be re-run — the worst possible state.

## Plugins see the tree, not the disk

A plugin receives the file tree and returns another one. It has no filesystem access, which makes every plugin testable with one assertion on an object.
