An API skeleton that ships with the boring parts already solved: authentication, request limiting and documentation that cannot go stale.

## Schema as the single source

Every route declares its schema with Zod. From it come, at the same time, runtime validation, the TypeScript types and the OpenAPI document. There is no separate step for writing documentation, so there is no wrong documentation.

## Rate limit by identity, not by IP

Counting by IP punishes a whole office behind one NAT. The counter uses the JWT `sub` when it exists and falls back to the IP only on public routes.
