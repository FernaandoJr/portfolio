Gerador de projeto que parte de um repositório real em vez de um template embutido. O template é um repo que você mantém como qualquer outro código.

## Nada é escrito antes do fim

Os arquivos são montados em memória e só vão para o disco quando todos os passos passam. Um scaffolding que falha na metade deixa uma pasta que não compila e não dá para reexecutar — o pior estado possível.

## Plugins que veem a árvore, não o disco

Um plugin recebe a árvore de arquivos e devolve outra. Ele não tem acesso ao filesystem, o que torna cada plugin testável com uma asserção sobre um objeto.
