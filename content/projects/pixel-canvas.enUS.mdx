A shared canvas where several people draw at the same time. Every cell is a real pixel, and the drawing belongs to the group, not to whoever arrived first.

## Draw locally, confirm later

The pixel shows up immediately and only then goes to the server. If the server rejects it, it reverts. Waiting for confirmation before painting gave the stroke a noticeable, uncomfortable lag.

## One canvas, not a thousand divs

The grid is a single `canvas` element. The first version used one `div` per cell and died at 64×64 — the browser is under no obligation to handle four thousand nodes changing color together.
